# IDS_GAN
Intrusion Detection System using GAN


To run this project, please download the datasets and models from https://drive.google.com/file/d/1eTfKI2LSD7ETD2_xNUnEZf6J1F5rW6BJ
and extract the folders into the root directory of this project before running app.py.


to run app.py on defender machine ,
run - python -m flask --app app run --host 0.0.0.0 --port 5000
